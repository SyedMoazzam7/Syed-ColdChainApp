# FrostLine Cold Chain: Business App

Class project for ITBT: a web app for a temperature-controlled logistics company.

- **Business:** Cold Chain Logistics Company (Vadodara, Gujarat)
- **Problem:** Customers cannot see or prove that temperature-sensitive cargo stayed in range.
- **Customer:** Pharma distributors, dairies, seafood exporters, ice-cream makers.
- **App:** Operations dashboard + shipment tracker + cost calculator + enquiry form.
- **Interactive feature:** Track order (try TRK1025 to TRK1028).
- **Dashboard:** orders, delivered, in transit, delayed, on-time %, temperature excursions, fleet utilisation, 7-day on-time chart, filter by cargo type.

All data is sample data. Built with HTML, CSS and JavaScript only.
